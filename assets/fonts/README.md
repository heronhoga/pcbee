# IBM Plex Mono

`IBMPlexMono-Regular.ttf` is the unmodified IBM Plex Mono Regular font from
https://github.com/google/fonts/tree/main/ofl/ibmplexmono.

Copyright 2017 IBM Corp. Reserved Font Name: Plex.
Redistributed under the SIL Open Font License 1.1 in `OFL.txt`.

The font is bundled with PCBEE; it does not need to be installed on the system.
